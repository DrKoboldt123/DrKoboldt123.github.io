Datenschutzerklärung

1. Verantwortlich

DrKobold, E-Mail: curlsclout@icloud.com

2. Welche Daten Kanal-Radar verarbeitet

Ausschließlich Daten der eigenen Konten des Betreibers, abgerufen über die offiziellen Schnittstellen:

  • Profilkennzahlen: Benutzername, Anzeigename, Konto-ID, Follower, Anzahl der Videos
  • Videodaten: ID, Titel bzw. Beschreibung, Veröffentlichungszeit, Länge, Link
  • Statistiken: Aufrufe, Likes, Kommentaranzahl, Shares, Gespeichert, Reichweite, Sehdauer
  • Zugangsschlüssel (Tokens) der Schnittstellen

Kanal-Radar liest keine Kommentartexte, Nachrichten oder Daten anderer Personen.

3. Zweck

Auswertung der Entwicklung der eigenen Kanäle durch den Betreiber.

4. Speicherung und Weitergabe

Alle Daten werden ausschließlich lokal auf dem Computer des Betreibers gespeichert (eine Datenbankdatei; die Zugangsschlüssel im Schlüsselbund des Betriebssystems). Es gibt keinen Server, keine Weitergabe an Dritte, keine Werbung und kein Tracking.

5. Speicherdauer und Löschung

Die Daten bleiben gespeichert, bis der Betreiber sie löscht. Wird eine Verbindung in den Einstellungen der Plattform widerrufen, kann Kanal-Radar keine neuen Daten mehr abrufen.

6. Diese Website

Diese Seite wird über GitHub Pages bereitgestellt. Sie setzt keine Cookies und enthält keine Analyse-Werkzeuge. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse (siehe Datenschutzerklärung von GitHub).

7. Rechte

Auskunft, Berichtigung und Löschung nach der DSGVO: Anfrage an die oben genannte E-Mail-Adresse.

Privacy Policy (English)

Controller: DrKobold, curlsclout@icloud.com. Kanal-Radar processes only data of the operator's own accounts, retrieved via the official APIs: profile figures (username, display name, account ID, followers, video count), video data (ID, title/description, publish time, duration, link), statistics (views, likes, comment count, shares, saves, reach, watch time) and API access tokens. It does not read comment texts, messages or any data of other people. All data is stored only locally on the operator's computer (a database file; tokens in the operating system's keychain). There is no server, no sharing with third parties, no advertising and no tracking. Data is kept until the operator deletes it; access can be revoked at any time in each platform's settings. This website is hosted on GitHub Pages, sets no cookies and uses no analytics; GitHub processes technically necessary data such as IP addresses.
